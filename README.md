# Easyspearfishing V2.14

Atualização do índice de pesca submarina.

- Mantém previsão de 7 dias e memória das últimas 72h.
- O score usa como zona favorável: período <=10 s, ondulação <1 m, rajadas <10 km/h e energia <=200 kJ.
- Vento de leste pode dar um pequeno bónus de limpeza, sem ser tratado como garantia.
- A visibilidade subaquática estimada também entra no índice final.
- Horas noturnas não são usadas para encontrar a melhor janela.
- Não é uma medição direta de visibilidade nem uma leitura direta da energia de serviços externos.
